Installation

Derush Tool se présente sous forme d'un fichier exécutable unique (DerushTool.exe sur Windows). Aucune installation requise — il suffit de le lancer.

Prérequis : ffmpeg doit être installé et accessible dans le PATH système, ou copié à côté de l'exécutable.

Première ouverture

Au premier lancement, l'assistant de configuration s'ouvre automatiquement dans le navigateur.

1
Dossier de travail — choisissez où stocker vos projets (fichiers JSON, waveforms, miniatures). Si vous avez déjà un dossier existant, pointez directement dessus. Le port réseau (défaut : 8765) permet l'accès depuis un autre appareil sur le réseau local.
2
Votre profil — créez votre identifiant et mot de passe. Ce profil est propre à cette machine et sera reconnu sur tous les projets que vous créez ou rejoignez.
3
Terminé — cliquez sur "Accéder à l'application".
Config stockée dans : %APPDATA%\DerushTool\ (Windows). Elle persiste entre les mises à jour du logiciel.

Connexion

À chaque lancement, l'application s'ouvre sur l'écran de connexion. Saisissez l'identifiant et le mot de passe définis lors du premier lancement.

Auto-login : Si vous étiez connecté lors de la dernière session, vous êtes automatiquement reconnecté et redirigé vers votre projet.

Créer un projet

Depuis l'écran "Mes projets", cliquez sur + Nouveau projet.

  • Nom du projet — ex. DRIFT_CLUB
  • Dossier des rushs — chemin vers le dossier contenant vos fichiers vidéo (MXF, MP4, MOV…). Derush Tool scanne ce dossier récursivement.

Un scan initial est lancé automatiquement. Le projet apparaît dans la liste une fois terminé.

Formats supportés

Par défaut : .mxf, .mp4, .mov. Modifiable dans les réglages du projet.

Ouvrir un projet existant

Cliquez sur un projet dans la liste pour l'ouvrir. Si le projet est synchronisé en cloud, les annotations des collaborateurs sont téléchargées automatiquement à l'ouverture.

Inviter un collaborateur (admin)

Depuis le workspace, cliquez sur ⚙️ (gestion utilisateurs) dans la barre latérale.

1
Dans "Autoriser un utilisateur", saisissez l'identifiant du collaborateur (celui qu'il a choisi lors de son premier lancement).
2
Choisissez une couleur et le niveau d'accès (admin ou non).
3
Cliquez sur Autoriser. Une clé d'invitation à 8 caractères s'affiche — transmettez-la avec l'ID du projet au collaborateur.
4
Cliquez sur ☁️ Sync pour pousser le projet mis à jour vers le cloud avant que le collaborateur tente de le rejoindre.
Important : La clé d'invitation est à usage unique. Si le collaborateur la perd, vous devrez en générer une nouvelle depuis ⚙️.

Rejoindre un projet (collaborateur)

Sur votre propre PC, après avoir installé Derush Tool et créé votre profil :

1
Connectez-vous avec votre identifiant.
2
Cliquez sur 🔑 Rejoindre un projet (clé d'invitation).
3
Entrez l'ID du projet (ex. drift_club) et la clé d'invitation fournie par l'admin.
4
Le projet est téléchargé depuis le cloud et apparaît dans votre liste.

Chemin local des rushs

Chaque collaborateur peut avoir ses rushs dans un dossier différent sur son propre disque. Lors de la première ouverture du projet, une fenêtre vous demande de définir votre chemin local vers les fichiers vidéo.

  • Saisissez le chemin complet du dossier contenant les rushs sur votre machine.
  • Cliquez sur Valider.

Pour modifier ce chemin ultérieurement, cliquez sur le bouton 📁 dans la barre latérale du workspace.

Exemple : L'admin a ses rushs dans D:\Tournages\DRIFT_CLUB\, Paola les a dans E:\RUSHS\Drift\. Chacun configure son propre chemin, indépendamment.

L'interface du workspace

Barre latérale gauche

  • Liste des clips — triés par jour de tournage, avec miniature et tech-méta (caméra, durée, ISO, ouverture…)
  • Filtres — par rating, marqueurs, statut, caméra, jour
  • Recherche — texte libre sur nom de fichier, tags, notes

Zone principale

  • Lecteur vidéo — lecture du fichier source ou proxy
  • Timeline — barre de progression avec marqueurs colorés et forme d'onde audio
  • Panneau d'annotation (droite) — rating, statut, note globale, tags, marqueurs, avis équipe

Marqueurs

Les marqueurs identifient des moments précis dans un clip. Ils apparaissent sur la timeline et sont exportés dans DaVinci Resolve.

Créer un marqueur

Pendant la lecture, appuyez sur une touche de catégorie :

ToucheCatégorieCouleur dans DaVinci
M📌 Note généraleSand (ambre)
S🎵 Problème sonVert
T👁️ Problème imageBleu ciel
X❌ Zone à couperRouge

Les marqueurs peuvent être déplacés par glisser-déposer sur la timeline.

Dessin sur image

Après avoir créé un marqueur image (T), activez le mode dessin (✏️) pour annoter directement sur la vidéo.

Tags

Les tags permettent un classement libre. Dans le panneau de droite, cliquez dans la zone tags et tapez un tag suivi de Entrée ou ,. Cliquez sur le × d'un tag pour le supprimer. Les tags sont recherchables dans la barre de filtres.

Avis de l'équipe

Le panneau "Avis des autres" affiche les annotations de tous les collaborateurs pour le clip actif : rating, note, marqueurs, et discussions. Vous pouvez répondre à un marqueur en cliquant sur 💬 Répondre.

Rôles & permissions

Chaque collaborateur se voit attribuer un rôle à l'invitation. Le rôle détermine ce qu'il peut faire dans le projet.

RôleCe qu'il peut faire
AdminTout : gérer les utilisateurs, rescanner, annoter, voir
AnnotateurAnnoter (rating, marqueurs, notes, tags) et voir les avis des autres
LecteurVoir les clips et les annotations uniquement — aucune modification possible

L'admin choisit le rôle dans le formulaire d'invitation (menu déroulant "Rôle").

Lecture J/K/L

Les touches J, K, L permettent un contrôle rapide de la vitesse de lecture, à la façon des consoles de montage professionnelles.

ToucheAction
LLecture en avant — appuyer plusieurs fois pour accélérer : 1× → 2× → 4×
KPause immédiate (remet la vitesse à 1×)
JLecture en arrière — appuyer plusieurs fois pour accélérer : 1× → 2× → 4×
Astuce : K + L maintenu ensemble = avance image par image. Pareil avec K + J pour reculer image par image.

Comparaison de clips

Le bouton ⚡ Comparer ouvre une vue côte à côte de deux clips pour comparer des prises, des angles de caméra ou des performances.

Utilisation

1
Cliquez sur ⚡ Comparer. Le clip actif est automatiquement chargé dans le slot gauche.
2
Sélectionnez un second clip dans le menu déroulant du slot droit.
3
Utilisez les boutons ⏯ de chaque slot pour contrôler la lecture indépendamment.

Timeline & Marqueurs

Chaque slot dispose d'une timeline scrubable avec les marqueurs de tous les annotateurs. Cliquez sur un marqueur (point coloré) pour sauter directement à ce moment. Les marqueurs de l'info panel sont également cliquables.

Mode Sync

Activez 🔗 Sync pour synchroniser la position de lecture des deux vidéos — utile pour comparer deux prises identiques plan par plan.

Fermer la comparaison : cliquez sur ✕ Fermer ou appuyez sur Échap.

Multi-cam & son ingé

Quand plusieurs caméras filment la même scène en simultané, Derush Tool regroupe les clips dont les timecodes source se chevauchent. Le calage est frame-accurate quand les caméras sont jam-syncées avec une multiprise LTC commune, et le son ingé son peut être joué en référence dans le viewer multi-cam.

Deux sources de TC utilisées :
  • LTC audio (à décoder une fois) — le BZZZZ caractéristique enregistré sur une piste audio quand la caméra était connectée à une multiprise LTC. Frame-accurate, c'est le standard pro. La FS5 par exemple écrit le LTC sur la piste audio 2 (ou 1 selon config).
  • Tag format.timecode — TC inscrit dans les métadonnées du fichier par la caméra. Fiable pour les FX6 jam-syncées via SDI. Peu fiable pour les FS5 dont l'horloge interne dérive — pour elles, c'est le LTC audio qui compte.
Le logiciel utilise automatiquement le LTC quand il est disponible (à décoder via le bouton ci-dessous), sinon il retombe sur le tag format.timecode.

Étape 1 — 🎶 Décoder LTC (à faire une fois par projet)

Dans la modale 🎥 Multi-cam, cadre 🎶 LTC, cliquez sur 🎶 Décoder LTC. Le serveur scanne tous les clips, extrait l'audio canal L de leur proxy, détecte les signaux LTC, et stocke le vrai TC dans le projet.

1
Le bouton lance un job en background. Progress bar avec le nom du clip en cours.
2
Quand fini, message du type "45 avec LTC · 12 sans LTC". Les clips sans LTC sont ceux dont l'audio ne contient pas de signal LTC (caméra non connectée à la multiprise, GoPro, FX6 dont le TC est dans les métadonnées, etc.).
3
Décodage persistant : stocké dans le JSON projet, à faire une seule fois. Le bouton ↻ Re-décoder tout force un re-décodage si vous avez refait vos proxys.
Durée : quelques minutes pour 100-500 clips selon la machine (parallélisé, throttlé pour ne pas saturer le CPU).

Étape 2 — 🔍 Lancer la détection

Cliquez sur 🔍 Lancer la détection. Le serveur compare les TC (LTC prioritaire, sinon format.timecode) de tous les clips deux à deux dans chaque journée (en excluant les paires de même caméra) et crée un groupe pour chaque chevauchement. C'est instantané, même sur plusieurs centaines de clips.

Les groupes apparaissent comme propositions. Clic / Shift+clic pour sélectionner plusieurs, puis ✓ pour valider ou ✕ pour rejeter en masse. Chaque groupe porte le badge 📼 TC.

Détection incrémentale : vous pouvez relancer 🔍 Détecter à volonté. Chaque passage préserve les groupes validés et les propositions existantes (vos calages manuels ne sont jamais écrasés), et ne traite que les clips encore orphelins.
Clips sans matching possible : si une caméra a un TC cassé ET pas de LTC audio sur une journée, ses clips ne formeront aucune paire — c'est volontaire (mieux vaut un trou explicite qu'un faux match silencieux). Vous les calerez à la main dans DaVinci. Sur DRIFT par exemple : J02 Clip0001, J04 Clip0016/0029, tout J06 sont dans ce cas.

Indexer le son ingé son (optionnel)

Dans la même modale, section 📼 Son ingé : indiquez le chemin du dossier contenant les BWF/WAV de l'ingénieur son et cliquez Scanner. Ces fichiers servent uniquement à jouer une piste de référence dans le viewer multi-cam — ils n'influencent pas la détection.

Sources reconnues : les enregistreurs Sound Devices, Zaxcom, Zoom, Tascam, et tout fichier WAV/BWF avec champ TimeReference dans le BEXT. Le champ OriginationDate est aussi lu pour éviter de mélanger les jours de tournage.

🔊 Son ingé

Si un BWF couvre temporellement le groupe (date + TC), un bouton 🔊 Son ingé apparaît dans la toolbar. Activez-le pour entendre la piste de référence pendant que vous switchez entre les angles — toutes les pistes caméra sont alors muted. Le BWF est aligné automatiquement sur le clip le plus ancien du groupe via son TC. Aucun calage manuel possible : si le son n'est pas aligné, c'est que le BWF n'est pas le bon, ou que le TC d'une des sources est faux.

Caler les vidéos entre elles (◄ / ►)

Si malgré un calage TC réussi vous voyez que les angles secondaires sont décalés (très rare), nudgez-les avec les boutons ◄ / ► à droite du sélecteur de Pas (1 frame, 100 ms, 500 ms, 1 s). Cliquez 💾 pour sauvegarder les nouveaux offsets du groupe — ils seront restaurés à la prochaine ouverture.

Preview LUT

Derush Tool peut appliquer une LUT 3D (Look-Up Table) sur la preview vidéo pour visualiser l'étalonnage prévu sans quitter l'interface.

Charger une LUT

1
Cliquez sur 📂 LUT dans la barre de contrôle du lecteur.
2
Sélectionnez un fichier .cube (format ASCII standard).
3
La LUT s'applique immédiatement sur la vidéo en cours. Un badge LUT apparaît sur l'image.

Activer / désactiver

Le bouton 🎨 LUT (qui apparaît après le chargement) permet de basculer la LUT on/off pour comparer avec et sans étalonnage. La LUT reste mémorisée dans la session même quand elle est désactivée.

Fichiers Sony : Les LUTs Sony FX6 (format .cube ASCII) situées dans XDROOT/General/LUT/ sont directement compatibles.
Qualité de preview : La preview LUT est calculée en résolution réduite (≈ 480px) pour la fluidité. Elle est destinée à l'appréciation colorimétrique, pas à la validation finale.

Collaboration temps réel

Quand plusieurs utilisateurs travaillent en même temps sur le même projet (en réseau local ou avec sync cloud actif), les annotations se mettent à jour automatiquement sans avoir à rafraîchir la page.

  • Les notes et marqueurs d'un collaborateur apparaissent dans votre panneau "Avis des autres" dès qu'il les sauvegarde.
  • Les discussions (replies sur les marqueurs) se synchronisent en temps réel.
  • La connexion WebSocket est automatique — pas d'action requise. En cas de déconnexion réseau, elle se rétablit automatiquement.
Mode réseau local : pour de meilleures performances, désignez un PC comme serveur (celui qui fait tourner DerushTool.exe) et connectez les autres via le navigateur sur http://<ip-lan>:8765.

Cliquez sur 📤 Exporter en haut de la zone principale.

Workflow complet (recommandé)

1
Téléchargez le FCPXML complet et importez-le dans DaVinci : File › Import › Timeline…
2
Téléchargez le Markers EDL et importez-le : clic droit timeline › Timelines › Import › Timeline Markers from EDL

Timelines de selects

  • ⭐⭐⭐ uniquement, ⭐⭐ et plus, problèmes son, problèmes image, à couper
  • Subclips autour des marqueurs avec pré-roll/post-roll configurables

Synchronisation cloud

Le dot ☁️ en haut du workspace indique l'état : 🟢 synchronisé, 🔴 erreur, ⚫ non configuré.

La sync est automatique au démarrage et toutes les 10 minutes. Cliquez sur le bouton Sync pour la déclencher manuellement.

Merge sans conflit : chaque utilisateur n'écrit que ses propres annotations. Il n'y a pas de risque d'écraser le travail d'un collègue.

Dépannage

Le projet ne trouve pas les fichiers vidéo

Vérifiez le chemin des rushs (bouton 📁 dans la barre latérale), puis cliquez sur 🔄 Rescanner.

Erreur 403 lors de la synchronisation

La clé de synchronisation dans derush_config.json (sync_key) ne correspond pas à la valeur $SECRET_KEY dans le fichier PHP sur le serveur web.

Impossible de rejoindre un projet (clé invalide)

La clé est à usage unique — si elle a déjà été utilisée, l'admin doit en générer une nouvelle. Vérifiez aussi que l'identifiant correspond exactement à celui autorisé.

La vidéo ne se lit pas (MXF)

Les fichiers MXF ne se lisent pas dans le navigateur. Deux solutions :

  • Proxy MP4 H.264 détecté automatiquement dans un sous-dossier Sub/Proxy/.
  • Mode réseau local avec streaming ffmpeg.

Le serveur persiste après fermeture de l'onglet

Derush Tool s'arrête automatiquement ~12s après la fermeture (heartbeat). Sinon, utilisez le bouton ⏻ dans l'interface avant de fermer, ou terminez le processus dans le Gestionnaire des tâches.

La preview LUT reste noire

Vérifiez que le fichier .cube est bien au format ASCII standard (ouvrir dans un éditeur de texte — la première ligne doit contenir LUT_3D_SIZE ou un commentaire #). Les LUTs Sony FX6 au format .cube sont compatibles. Les LUTs en format propriétaire binaire ne le sont pas.

Les clips dans la vue Comparer ne sont pas à la même hauteur

Cela peut arriver si les deux clips ont des formats d'image très différents (ex. 16:9 vs 4:3). C'est normal — les deux videos sont centrées dans leurs zones respectives. Les timelines restent toujours alignées.

Les marqueurs n'apparaissent pas dans la timeline de comparaison

Les marqueurs s'affichent après le chargement complet des métadonnées vidéo. Attendez que la vidéo soit entièrement chargée (barre de chargement terminée), puis changez de clip et revenez si nécessaire pour forcer le rechargement.

La collaboration temps réel ne se met pas à jour

La connexion WebSocket peut se déconnecter si le réseau est instable. Elle se reconnecte automatiquement toutes les 6 secondes. Si le problème persiste, rechargez la page (F5) — vos annotations locales non sauvegardées seront perdues, pensez à sauvegarder d'abord avec 💾 Sauvegarder.

Aucun groupe multi-cam détecté alors que deux caméras ont filmé la même scène

La détection se fait uniquement par TC source. Si la détection ne trouve rien, c'est presque toujours qu'une des deux caméras a un TC incohérent ce jour-là (jam-sync raté, TC reseté en cours de journée, dérive de plusieurs heures). Dans ce cas, pas de méthode de secours automatique : il faut caler les plans à la main dans DaVinci pour les jours concernés.

Vérifications utiles :

  • Ouvrez les deux clips concernés et regardez leur TC source dans le panneau d'infos. S'ils sont à plus de quelques secondes l'un de l'autre alors que les plans ont été filmés au même moment, le TC d'au moins une caméra est faux.
  • Sur les autres jours (où le TC est cohérent), la détection trouve les paires instantanément — un projet où ça ne marche jamais signale plutôt un souci de scan ou de métadonnées que de la méthode.

Le son ingé son est décalé dans le viewer multi-cam

Le BWF est aligné automatiquement sur le clip le plus ancien du groupe via son TC. S'il sonne décalé, deux possibilités :

  • Pas le bon BWF : le serveur choisit le BWF qui couvre temporellement le groupe (TC + date) et démarre juste avant le premier clip. Si plusieurs BWF du même horaire existent (tech checks, essais mic), un mauvais peut être pris. Aucun calage manuel disponible — il faut renommer ou déplacer les BWF de tech check hors du dossier scanné, puis re-scanner.
  • TC source faux : si le TC de la caméra est incohérent, le BWF est calé sur une mauvaise référence. C'est le même problème que pour la détection des groupes : à caler à la main dans DaVinci pour cette journée.

Les deux vidéos d'un groupe multi-cam sont décalées entre elles

Si une paire détectée par TC montre malgré tout un décalage à l'écran (très rare), nudgez les angles secondaires dans le viewer :

  1. Choisissez le Pas dans la toolbar (1 frame / 100 ms / 500 ms / 1 s).
  2. Utilisez ◄ / ► à droite du sélecteur jusqu'à alignement visuel.
  3. 💾 pour sauvegarder les nouveaux offsets du groupe.
